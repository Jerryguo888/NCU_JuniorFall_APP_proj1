# 功能及使用者驗收

## 自動化檢查

```powershell
npm test
npm run check
npm run build
```

測試涵蓋跨年、閏年、週起始、無效日期／時段、重疊及相接邊界、空檔合併、規劃優先順序與過去時段、備份完整驗證、AI 請求最小化，以及拒絕模型重疊／異日／過期建議。這些測試沒有對正式 Firebase 或 Gemini 發送請求。
